# ⚡ Ledgr — Personal & Business Finance Tracker

Built with React + Vite. Deploys instantly to Vercel.

---

## 🚀 Run Locally

1. Install [Node.js](https://nodejs.org) (LTS version)
2. Open this folder in VS Code
3. Open terminal (`Ctrl + `` `) and run:

```
npm install
npm run dev
```

App opens at `http://localhost:5173`

---

## 🌍 Deploy to Vercel

### Via GitHub (recommended):
```
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/ledgr.git
git push -u origin main
```

Then go to [vercel.com](https://vercel.com) → New Project → Import your repo → Deploy.

Vercel auto-detects Vite. No configuration needed.
